# ESP32-C3 Super Mini 多传感器项目

基于 **ESP-IDF v6.1**（新版 `i2c_master` API）的完整工程，在 128×64 SSD1315 OLED
单页显示 SHT40、GY-91（BMP280 + MPU6500/MPU9250 + AK8963）的全部数据，不翻页。

## 1. 硬件接线

| 信号 | GPIO | 说明 |
| --- | --- | --- |
| SDA | GPIO8 | I2C 数据线 |
| SCL | GPIO9 | I2C 时钟线 |
| VCC | 3.3V | 所有模块供电（严禁 5V） |
| GND | GND | 共地 |

I2C 地址：

| 器件 | 地址 | 功能 |
| --- | --- | --- |
| SHT40 | 0x44 | 温湿度 |
| BMP280 | 0x76 | 温度 + 气压 + 海拔（GY-91） |
| MPU9250 | 0x68 | 加速度 + 陀螺仪（GY-91） |
| AK8963 | 0x0C | 磁力计（仅正品 MPU9250/9255 内置，需 I2C Bypass） |
| SSD1315 | 0x3C | 128×64 OLED（兼容 SSD1306 指令集） |

## 4. 显示布局（单页，21 字符 × 8 行）

```
SHT 25.30C 56.20%
BMP 24.80 1013.00hPa
ALT 32.00m I2C:OK
A 0.12 -0.05  0.99
G 12.34 46.78 -5.12
M 45.12 -23.34 12.56
R 12.30P -3.10Y 45.60
Up:00:05:23 Heap:123K
```

> 所有数值均为**固定宽度、右对齐、2 位小数**，因此小数点位置不会随数值变化而左右跳动。
> 为在 21 字符宽度内排下，三轴数据行使用单字母标签 `A`（加速度）/`G`（陀螺仪）/`M`（磁力计），
> 角度行用 `R`/`P`/`Y`；单位在下方表格中说明。

上例为**正品九轴模块**的输出；MPU6500（无磁力计）时 M 行显示 `---`。

每行数据的含义、来源与单位：

| 行 | 字段 | 含义 | 来源 | 单位 | 格式 |
| --- | --- | --- | --- | --- | --- |
| 0 | `SHT 25.30C 56.20%` | 温度 / 相对湿度 | SHT40 | ℃ / %RH | 固定宽 2 位小数 |
| 1 | `BMP 24.80 1013.00hPa` | 温度 / 气压 | BMP280 | ℃ / hPa | 固定宽 2 位小数 |
| 2 | `ALT 32.00m I2C:OK` | 海拔 + I2C 在线状态 | BMP280 / 启动扫描 | m / 个 | 固定宽 2 位小数 |
| 3 | `A 0.12 -0.05 0.99` | 三轴加速度 X / Y / Z | MPU 加速度计 | g（重力倍数） | 固定宽 2 位小数 |
| 4 | `G 12.34 46.78 -5.12` | 三轴角速度 X / Y / Z | MPU 陀螺仪（零偏补偿后） | °/s | 固定宽 2 位小数 |
| 5 | `M 45.12 -23.34 12.56` | 三轴磁场 X / Y / Z | AK8963 | µT | 固定宽 2 位小数 |
| 6 | `R 12.30P -3.10Y 45.60` | 姿态角 Roll / Pitch / Yaw | 滤波+零偏校准+Mahony | ° | 固定宽 2 位小数 |
| 7 | `Up:00:05:23 Heap:123K` | 运行时间 + 空闲堆 | 系统 | 时:分:秒 / KB | — |

补充说明：

- **A（加速度）**：静止时 Z 轴约 `1.00`（重力），X/Y 接近 0；数值为 g，不是 m/s²。
- **G（陀螺仪）**：静止时接近 `0.00`；已做零偏校准，单位为 °/s。
- **M（磁力计）**：µT；三轴全为 0（无磁力计或读取失败）时整行显示 `---`。
- **R/P/Y**：Roll/Pitch 有加速度计绝对参考较稳定；Yaw 依赖磁力计，无磁力计时会漂移。
- **校准指示 `CAL`**：上电后约 2 秒的陀螺零偏校准阶段，显示在第 2 行（替代 I2C 状态），
  此时请保持模块静止，校准完成后自动显示角度。
- 所有数值右对齐到固定宽度，小数点位置固定；无效数据显示为固定宽度的 `---`。
- 数值超出字段宽度时（如陀螺仪超过 ±999.99），该行会临时变宽、末位可能被裁掉。
- 传感器离线时对应行显示 `---`，程序不会卡死。
- 环境传感器每 50ms 采集一次，IMU 以 100Hz 独立采集，显示刷新周期默认 20ms（见 `IMU_PERIOD_MS` / `DISPLAY_PERIOD_MS`）。

## 5. 已知限制说明

1. **I2C 总线长度**
   - 400kHz 下总线走线建议 ≤ 30cm，且尽量短、远离高频/电源走线。
   - 线缆过长或电容过大时会出现 NACK / 数据错乱，可降低到 100kHz。

2. **上拉电阻**
   - 代码仅开启了 ESP32-C3 内部弱上拉（`enable_internal_pullup = true`），
     在 400kHz 下通常不足以保证波形质量。
   - **强烈建议** SDA/SCL 各外接 4.7kΩ 上拉到 3.3V（GY-91、OLED 模块大多已自带，
     但仍需确认）。缺失上拉会表现为设备随机掉线。

3. **供电**
   - 所有模块必须使用 3.3V，严禁 5V，否则可能损坏 ESP32-C3 的 IO。
   - GY-91 同时含气压计与九轴 IMU，峰值电流较大，建议电源加 10µF~100µF 去耦。

4. **磁力计校准**
   - 驱动已在初始化时读取 AK8963 Fuse ROM 的出厂灵敏度调整值（`ASAX/AY/AZ`），
     并对三轴读数逐轴修正（系数 `(ASA-128)/256 + 1`）。
   - 但**未做硬铁/软铁校准**：μT 绝对值和 Yaw 仍会受周围铁磁材料、电机、
     走线电流影响。如需高精度航向，请做 8 字校准并写入硬铁偏移/软铁矩阵。

5. **AK8963 工作模式与灵敏度**
   - AK8963 `CNTL1` 的 bit4 为输出位宽选择（1 = 16 位）。任务书给出的 `0x06`
     实为 14 位模式（灵敏度 0.6 µT/LSB），与 `0.15 µT/LSB` 不匹配。
   - 本工程采用 **`0x16`（16 位连续测量模式 2）+ 0.15 µT/LSB**，读数正确。
     若需严格按 `0x06`，请同时把 `MPU9250_MAG_UT_PER_LSB` 改为 `0.6f`。
   - 读取时先轮询 `ST1.DRDY`，再从 `HXL(0x03)` 突发读 7 字节（小端序，含 `ST2`），
     并检查 `ST2.HOFL` 溢出标志，避免读到混合/无效数据。

6. **BMP280 海拔**
   - 海拔公式以海平面标准大气压 101325 Pa 为基准，实际天气变化会导致
     数十米误差；如需精确海拔请根据当地气压修正基准值。

7. **温度/气压耦合**
   - 气压补偿依赖温度补偿得到的 `t_fine`，因此每次读取都先算温度。
     若温度校准异常导致 `t_fine` 不可用，气压同样会被标记为无效。

8. **SSD1315 兼容性**
   - SSD1315 指令集兼容 SSD1306，本驱动使用任务书给定的初始化序列。
     个别批次的 SSD1315 需要将对比度（0x81）或预充电（0xD9）微调。

9. **姿态融合与陀螺漂移抑制**
   - 姿态流水线：**硬件 DLPF → 突发读 → 二阶低通滤波 → 陀螺零偏校准/静止跟踪 → Mahony 融合**。
   - `mpu9250`：
     - 陀螺硬件 DLPF 20Hz、加速度 DLPF 21Hz，在进入软件滤波前先压高频噪声。
     - `0x3B~0x48` 一次突发读 14 字节（加速度+温度+陀螺），保证同帧一致，并取得片内温度。
   - `imu_filter`：加速度 20Hz、陀螺仪 16Hz 二阶 Butterworth 低通（100Hz 采样）；
     **首帧用真实采样播种状态**，不再有 2 秒直通期，避免“直通→滤波”跳变污染零偏校准。
   - `imu_bias_calib`：
     - 上电后累计 200 帧（约 2s）静止样本求均值作为陀螺零偏；静止判据为
       **陀螺绝对值/帧间变化 + 加速度模长接近 1g**，运动帧会清空累计重新等待。
       若持续运动或零偏过大导致 10s 内未采够，则超时强制结束（零偏交由运行期跟踪收敛），
       保证姿态不会因校准不完成而永不输出。
     - 运行期用补偿后残差 + 帧间变化 + 加速度量级/变化做静止检测（连续 30 帧约 300ms 才置位）。
     - 帧间稳定时按 0.002/0.008 双速低通跟踪零偏；残差暂超阈值但仍在可恢复范围内
       时用慢速兜底跟踪，避免温漂把零偏推出阈值后永久锁死。
     - **在线估计陀螺零偏温漂系数**（dps/℃）：静止跟踪时若温度变化 ≥0.3℃，
       用 Δbias/ΔT 更新；置信度足够后，在非静止无法跟踪时按温度外推补偿。
     - 加速度零偏仅在接近水平静止时标定（|mean_z|≥0.9），避免倾斜时误扣重力。
   - **校准完成前不喂融合器**（`fusion_armed`）：避免未补偿零偏先把四元数积分脏。
   - **静止自适应 Mahony**：静止时 Kp/Ki 提到 1.0/0.005，运动时压到 0.8/0.0005，
     减少线加速度对姿态的污染，同时加速静止时残余零偏收敛。
   - **加速度模长门控**：|a| 不在 0.75~1.25g 时，该帧不用加速度/磁力计校正，退化为纯陀螺积分，
     避免推拉/振动被当成倾斜。
   - **积分反馈限幅** ±2 dps：防止干扰把 Mahony integral_fb 灌飞。
   - **ZUPT**：静止且补偿后残差 < 0.20°/s 时，融合输入角速度强制置 0，
     避免噪声积分成 Yaw 漂移。
   - **100Hz 定时**：`vTaskDelayUntil` 固定相位延时，补偿本轮 I2C/计算耗时，减少积分抖动。
   - Mahony Kp 随静止/运动切换；磁力计未校准时建议仅参考 Roll/Pitch，Yaw 仅作趋势观察。
   - MPU6500 无磁力计时，融合自动退化为六轴：Roll/Pitch 仍稳定，**Yaw 无绝对
     参考会缓慢漂移**（ZUPT + 零偏跟踪 + 温漂补偿可显著减慢，但无法消除）。
   - 陀螺量程 **±500dps**（`FS_SEL=01`，65.5 LSB/°/s），分辨率优于 ±2000dps；
     手持姿态场景通常不会饱和。IMU 独立任务 100Hz（`IMU_PERIOD_MS = 10`）。

10. **共享数据结构**
    - `sensor_task` 与 `display_task` 通过 `SemaphoreHandle_t` 互斥锁保护
      `sensor_data_t`；I2C 总线访问由 ESP-IDF 新版 I2C master 驱动内部串行化。

## 6. 实测结论（ESP32-C3 Super Mini + GY-91 + SHT40 + SSD1315）

本工程在实机上调试得到以下结论，供接线参考：

1. **OLED 供电务必确认**
   - 单独测试时曾因忘记给 OLED 接 VCC 导致 0x3C 扫不到；务必确认 OLED 的 VCC 接 3.3V。
   - 若高码率（400kHz）下出现长数据写入超时，再优先检查上拉电阻与线材长度。
   - 降速（`I2C_SCL_SPEED_HZ` 改 100000/10000）可作为快速排查手段。

2. **GY-91 实际为 MPU6500 + BMP280**
   - 读取 WHOAMI 返回 **0x70（MPU6500）**，而非 0x71（MPU9250），且 0x0C 无 AK8963。
     这是 GY-91 常见的“标 MPU9250 实为 MPU6500”翻新版本。
   - WHOAMI 对应关系：**0x70 = MPU6500（无磁力计）/ 0x71 = MPU9250 / 0x73 = MPU9255**。
     驱动对三者均兼容：0x71/0x73 初始化 AK8963，0x70 自动退化为六轴。
   - MPU6500 下加速度/陀螺仪/姿态可用，**无磁力计**，磁力计行显示 `MAG --- --- --- uT`，
     Yaw 会缓慢漂移。
   - 旁路后会自动探测 `0x0C/0x0D/0x1E`，若山寨板外挂了独立磁力计（如 QMC5883L）
     会打印告警，便于后续适配。

3. **I2C 时钟是“按设备”设置的**
   - ESP-IDF v6.1 新版驱动的时钟在 `i2c_device_config_t.scl_speed_hz`，总线配置结构体
     没有时钟字段；因此统一改速必须改 `main/i2c_config.h` 的 `I2C_SCL_SPEED_HZ`。
